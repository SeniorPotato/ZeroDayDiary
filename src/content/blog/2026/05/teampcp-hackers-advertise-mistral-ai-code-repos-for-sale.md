## What happened
Recent reporting highlighted teampcp hackers advertise mistral ai code repos for sale. The TeamPCP hacker group is threatening to leak source code from the Mistral AI project unless a buyer is found for the data. In a post on a hacker forum, the threat actor is asking $25,000 for a set of nearly 450 repositories.
