## What happened
Recent reporting highlighted max-severity flaw in chromadb for ai apps allows server hijacking. A max-severity vulnerability in the latest Python FastAPI version of the ChromaDB project allows unauthenticated attackers to run arbitrary code on exposed servers. The flaw is tracked as CVE-2026-45829 and was reported to ChromaDB on February 17.
