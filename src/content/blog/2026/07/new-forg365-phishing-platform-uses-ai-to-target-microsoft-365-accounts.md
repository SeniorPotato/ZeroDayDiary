## What happened
Recent reporting highlighted new forg365 phishing platform uses ai to target microsoft 365 accounts. A new phishing-as-a-service (PhaaS) operation called Forg365 focuses on stealing Microsoft 365 accounts by combining adversary-in-the-middle (AiTM) and device code methods with AI-assisted lure generation. The platform also provides a browser extension for continued access to the Microsoft services linked to the compromised accounts without the need to re-authenticate.
