## What happened
Recent reporting highlighted malicious claude code extension on cursor planted ssh backdoors. A malicious version of Anthropic's Claude Code VS Code extension was distributed through Cursor's extension marketplace for approximately 11 hours on October 29, exposing up to 5,000 developers to malware designed to install persistent SSH backdoors. The extension used the version number 2.1.313 and was distributed between 2:27 a.m.
