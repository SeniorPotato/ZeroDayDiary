## What happened
Recent reporting highlighted github announces npm security changes to tackle supply-chain attacks. GitHub has announced that npm v12, expected next month, will introduce several security-focused changes aimed at blocking supply-chain attacks abusing behaviors triggered by the 'npm install' command. 'npm install' is the command used to download and install a project's dependencies and run any install-related scripts defined by the packages.
