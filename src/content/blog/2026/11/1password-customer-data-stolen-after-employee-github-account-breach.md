## What happened
Recent reporting highlighted 1password customer data stolen after employee github account breach. 1Password has disclosed a data breach after an employee's corporate GitHub account was hacked and used to deploy malicious code to the company's backend services to steal customer data. The company says customer password vaults and the encryption keys protecting them were not compromised in the attack.
