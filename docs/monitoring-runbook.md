# Monitoring Runbook

## Quick daily routine
1. Review candidate items in `data/monitoring/intake.md`
2. Move worthwhile events to `data/monitoring/queue.md`
3. Draft one or more entries from the queue
4. Publish either:
   - a single event entry, or
   - a short watchlist note if verification is still partial

## Decision rule
Use a **watchlist** post when:
- the signal appears important
- the sourcing picture is still developing
- there is value in logging it without overstating certainty

Use an **event entry** when:
- there is a credible evidence base
- the event has clear stakes
- the facts are stable enough to summarise cleanly

## Content types
- Event entry
- Watchlist
- Analysis
- Roundup

## Escalation trigger
Escalate an item to featured status if:
- it affects multiple regions or sectors
- it changes public policy or enforcement posture
- it indicates a repeatable pattern
- it materially changes assumptions about AI safety, privacy, or infrastructure risk
