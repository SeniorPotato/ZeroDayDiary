# Content Operations Mode

ZeroDayDiary is now operating in content-ops mode.

## Mode definition
The site is no longer just being designed or scaffolded. It now has an active editorial operating loop:
- discover
- triage
- classify
- draft
- publish
- archive

## Current publishing mix
- daily / near-daily watchlists when signal volume justifies it
- event entries when there is a concrete development with durable relevance
- analysis pieces when patterns emerge across multiple events

## Constraints
- no newsletter list operations
- no PII collection
- no pressure to publish filler
- no obligation to mirror the mainstream news cycle

## Editorial objective
Become a reliable global reference point for:
- breaches
- privacy changes
- surveillance expansion
- AI deployment risk
- governance shifts

## Operational standard
If a post does not improve the archive, it should not be published.
